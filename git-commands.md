Git Commands

1. "git init" – Initialize a repository.
2. "git add" – Stage files for committing.
3. "git commit" – Save changes in the repository.
4. "git status" – Check the status of files.
5. "git log" – View commit history.
6. "git push" – Upload commits to GitHub.
7. "git pull" – Download changes from a remote repository.

Git vs GitHub

- Git is a version control system.
- GitHub is an online platform for hosting Git repositories.
